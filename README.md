# Реализованные классы
 `Table` (в `memory.py`)
Представляет отдельную таблицу с произвольными колонками.
# Атрибуты:
- `name` — имя таблицы
- `columns` — список названий колонок
- `records` — список записей

# Методы:
- `add_record()` — добавление записи
- `get_records()` — получение записей с фильтрацией
- `update_records()` — обновление записей по фильтру
- `delete_records()` — удаление записей по фильтру
- `clear()` — очистка всех записей
- `rename_column()` — переименование колонки
- `sort_records()` — сортировка записей по колонке
- `get_record_by_index()`, `delete_record_by_index()`, `update_record_by_index()` — работа по индексам

`Database` (в `memory.py`)
Управляет коллекцией таблиц.

# Методы:
- `create_table()` — создание таблицы
- `list_tables()` — список таблиц
- `get_table()` — получение таблицы по имени
- `delete_table()` — удаление таблицы
- `rename_table()` — переименование таблицы
- `table_exists()` — проверка существования
- `get_all_info()` — информация о всех таблицах
- `sort_records()` — сортировка записей в таблице
- CRUD-операции через таблицы

`TUI` (в `tui.py`)
Текстовый пользовательский интерфейс.

# Атрибуты:
- `_current_table` — текущая выбранная таблица

# Методы:
- `run()` — главный цикл программы
- `_print_menu()` — отображение меню
- `_sort_records()` — сортировка записей
- Все методы для работы с пользователем (`_create_new_table`, `_add_record`, и т.д.)

# Исключения (`errors.py`)

- `TableError` — базовый класс
- `TableNotFoundError` — таблица не найдена
- `ColumnNotFoundError` — колонка не найдена
- `DuplicateTableError` — дубликат таблицы
- `EmptyTableNameError` — пустое имя таблицы
- `EmptyColumnsError` — нет колонок
- `InvalidRecordLengthError` — неверная длина записи
- `RecordNotFoundError` — запись не найдена по индексу

# Функциональность

### Управление таблицами
- Создание таблиц(_create_new_table()) — пользователь задаёт имя и список колонок 
- Просмотр таблиц(_show_tables()) — список всех таблиц с количеством записей и колонок
- Просмотр информации конкретной таблицы(_show_current_table_info()) — информации конкретной таблицы с количеством записей и колонок
- Выбор текущей таблицы(_select_table()) — все операции применяются к выбранной таблице 
- Переименование таблиц(_rename_table()) — изменение имени существующей таблицы 
- Удаление таблиц(_delete_table()) — полное удаление таблицы со всеми записями
- Переименование колонок таблицы(rename_column()) - меняет название колонок выбранной таблицы

### Работа с записями (CRUD)
- Добавление записей(insert_record()/_add_record()) — ввод значений по колонкам с проверкой количества полей
- Просмотр всех записей(_show_all_records()) — отображение всех записей текущей таблицы
- Поиск по фильтру (select_records())- фильтрация по значениям любых колонок (формат `колонка=значение`)
- Сортировка записей по любой колонке (возрастание/убывание) (sort_records()) -  сортировки записей по выбранному полю в порядке возрастания или убывания
- Обновление записей(update_records()) — массовое обновление с выбором конкретных записей
- Удаление записей(delete_records()) — два варианта:
  - по фильтру (любые колонки)(_delete_by_filter())
  - очистка всей таблицы(_clear_table())

### Особенности
- Фиксированная структура таблиц
- Именованные колонки для фильтрации
- Подтверждение массовых операций
- Полная обратная совместимость с процедурной версией
