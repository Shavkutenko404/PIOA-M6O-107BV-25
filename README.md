## Описание проекта

Консольное приложение для управления базой данных с возможностью выбора типа хранилища:
- **In-memory** — данные живут только во время работы программы
- **File database (JSON)** — данные сохраняются в файлы и доступны после перезапуска

## Реализованные классы

### `Database` (в `database.py`)
Абстрактный класс, задающий единый интерфейс для всех реализаций БД.

### `MemoryDatabase` (в `memory.py`)
In-memory реализация. Данные хранятся в оперативной памяти, при завершении программы теряются.

### `FileDatabase` (в `file.py`)
Файловая реализация с хранением в JSON.

**Особенности:**
- Каждая таблица сохраняется в отдельный файл `data/имя_таблицы.json`
- Автоматическое создание папки `data/`
- Обработка ошибок при чтении/записи

### `Table` (в `table.py`)
Представляет отдельную таблицу с произвольными колонками.

**Атрибуты:**
- `name` — имя таблицы
- `columns` — список названий колонок
- `records` — список записей (кортежи)

**Методы:**
- `add_record()` — добавление записи
- `get_records()` — получение записей с фильтрацией
- `update_records()` — обновление записей по фильтру
- `delete_records()` — удаление записей по фильтру
- `clear()` — очистка всех записей
- `rename_column()` — переименование колонки
- `sort_records()` — сортировка записей по колонке
- `get_record_by_index()`, `delete_record_by_index()`, `update_record_by_index()` — работа по индексам

### `TUI` (в `tui.py`)
Текстовый пользовательский интерфейс.

**Атрибуты:**
- `_current_table` — текущая выбранная таблица
- `_db` — экземпляр базы данных (MemoryDatabase или FileDatabase)

**Методы:**
- `run()` — главный цикл программы
- `_select_database_type()` — выбор типа БД при запуске
- Все методы для работы с пользователем

## Функциональность

### Управление таблицами
- Создание таблиц с произвольными колонками
- Просмотр всех таблиц
- Информация о текущей таблице
- Выбор текущей таблицы
- Переименование таблиц
- Удаление таблиц
- Переименование колонок

### Работа с записями (CRUD)
- Добавление записей с проверкой количества полей
- Просмотр всех записей
- Поиск по фильтру (формат `колонка=значение`)
- Сортировка записей по любой колонке (возрастание/убывание)
- Обновление записей с подтверждением
- Удаление записей:
  - по фильтру
  - очистка всей таблицы

### Особенности файловой версии
- Автоматическое создание папки `data/`
- Сохранение после каждой операции
- Загрузка из файлов при запуске
- Устойчивость к повреждённым файлам

## Сравнение реализаций

| Характеристика | In-memory | File database (JSON) |
|----------------|----------|--------------------|
| Скорость |  Быстро |  Медленнее (диск) |
| Сохранение |  Не сохраняется |  Сохраняется в файлы |
| Загрузка |  Не загружается |  Загружается при старте |
| Формат | Кортежи | JSON-файлы |
| Кэширование |  В оперативной памяти |  В памяти + файлы |

---

- Добавление записей(insert_record()/_add_record()) — ввод значений по колонкам с проверкой количества полей
- Просмотр всех записей(_show_all_records()) — отображение всех записей текущей таблицы
- Поиск по фильтру (select_records())- фильтрация по значениям любых колонок (формат `колонка=значение`)
- Сортировка записей по любой колонке (возрастание/убывание) (sort_records()) -  сортировки записей по выбранному полю в порядке возрастания или убывания
- Обновление записей(update_records()) — массовое обновление с выбором конкретных записей
- Удаление записей(delete_records()) — два варианта:
  - по фильтру (любые колонки)(_delete_by_filter())
  - очистка всей таблицы(_clear_table())

### Особенности
- Фиксированная структура таблиц
- Именованные колонки для фильтрации
- Подтверждение массовых операций
- Полная обратная совместимость с процедурной версией
